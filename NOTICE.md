# Notice

This file ships in the offline bundle, next to `THIRD_PARTY_NOTICES.md` (the
Python packages inside the `ke-app` image and the stack images, generated by
`scripts/bundle.sh` at bundle time) and `licenses/` (full licence texts).

Knowledge Engine is the code in this repository: the `ke-app` and
`ke-gateway` images, and the scripts and configuration under `app/` in the
bundle. Every third-party component below keeps its own licence. Nothing in
the bundle changes those licences.

## Vendor images

Each third-party image in the stack is pinned by digest. A row here is the
reviewed licence for exactly that digest: `scripts/bundle.sh` reads this table
and refuses to write a bundle for a digest-pinned stack image that has no row
with a licence. Changing a digest in `docker-compose.yml` therefore needs the
licence checked again and this row updated. Keep each cell on one line and
never put a pipe character in one.

## Base image of `ke-gateway`

`docker/gateway.Dockerfile` builds on
`nginxinc/nginx-unprivileged:1.28-alpine@sha256:7377697a821c131a924a7105fafbe7414db4e9fcc77a6f08f776f33f141ec3f8`
(nginx 1.28.2). The image packaging (`org.opencontainers.image.licenses`) is
Apache-2.0, from https://github.com/nginx/docker-nginx-unprivileged; nginx
itself is BSD-2-Clause (`/usr/share/licenses/nginx/COPYRIGHT` inside the
image). `ke-gateway` adds only configuration.

## psycopg (LGPL-3.0-only)

The `ke-app` image installs `psycopg` and `psycopg-binary` 3.3.6 from PyPI,
unmodified, under the GNU Lesser General Public License version 3 only
(`licenses/LGPL-3.0.txt`). The engine imports them as ordinary Python packages,
so a user can replace them with another build. The source of `psycopg` is the
sdist locked in `uv.lock`:
https://files.pythonhosted.org/packages/76/26/3ea4ca5eaea1c0debcdf7ee7c1613fbe721dc27a03c461c0817ffd8a0601/psycopg-3.3.6.tar.gz
(sha256 `c081f2250df751a943036e42db6df4571c66cd0aabe8291a7a506512b12007d2`);
the source of `psycopg-binary` is in the same upstream project,
https://github.com/psycopg/psycopg. Each package's own licence file stays in
the image under its `dist-info/licenses/` directory and is listed in
`THIRD_PARTY_NOTICES.md`.
